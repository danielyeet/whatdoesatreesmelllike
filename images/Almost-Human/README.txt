ALMOST HUMAN — the pictures for works/almost-human.html.

One picture per fragrance, named after the fragrance:

  burning-bridges.jpg  part 01
  dear-future.jpg      part 02
  desert-hope.jpg      part 03
  ritual-code.jpg      part 04
  silent-rain.jpg      part 05

Each part names its file in TWO places — the small square in the list
and the full picture inside it — so change both together.

A file that is not here yet is not a problem: almost-human.js takes the
<img> off the page, which puts the hatched placeholder back, so the
house looks unfinished rather than broken.

This folder's name uses a hyphen rather than a space on purpose: a
space becomes %20 in the address.

This file is also the only thing keeping this folder in the repository —
git does not store an empty directory. Don't delete it.
