PHOTOGRAPHY

The pictures for categories/other-2.html — the Photography page.

One file per frame. Put the photograph in here, then uncomment the
<img> in the frame's block on that page and give it an alt.

Keep the file names lowercase with hyphens rather than spaces: a space
becomes %20 in the address, and paths are case-sensitive on the live
site.

This file is also the only thing keeping this folder in the repository
— git does not store an empty directory — so leave it here until there
are pictures beside it.
