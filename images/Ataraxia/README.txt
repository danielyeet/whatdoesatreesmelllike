five files by name:

  ataraxia-01.jpg  part 01
  ataraxia-02.jpg  part 02
  ataraxia-03.jpg  part 03
  ataraxia-04.jpg  part 04
  ataraxia-05.jpg  part 05

They are named by NUMBER rather than by fragrance, because the
fragrances are not named yet. When they are, rename each file after its
fragrance and change the two places the page points at it — the small
square in the list and the full picture inside.

Each part names its file in TWO places, so change both together.

A file that is not here yet is not a problem: house.js takes the <img>
off the page, which puts the hatched placeholder back, so the house
looks unfinished rather than broken.

THE HOUSE'S PICTURE ON THE CONTACT SHEET is a separate thing and is
not here yet either. When it arrives, put it in this folder, make a
web copy of it no more than 1600px on its long edge, and uncomment the
<img> in the Ataraxia frame in categories/scent-descriptions.html.

This file is also the only thing keeping this folder in the repository —
git does not store an empty directory. Don't delete it.
